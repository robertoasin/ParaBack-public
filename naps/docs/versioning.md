# NaPS バージョン命名規則

PyPI（pynaps）公開を機に、バージョン表記を **PEP 440** 準拠に整理した。
本ドキュメントは今後の版番号の付け方を定める。

## 切り替えの方針

- **過去のコミット・タグは変更しない**。`1.03a38` … `1.04a9` といった旧表記は
  そのまま履歴に残す（履歴改変はしない）。
- **今後の版から新命名に移行する**。最初の新命名版は `1.4.1.dev1`。
- **PyPI（pynaps）には新命名の版のみ投入する**。本番 PyPI への初投入は
  正式版 **`1.4.1`** から（それ以前の `.devN` は TestPyPI での検証にのみ使う）。

## 旧命名（〜 1.04a9、参考）

`メジャー . マイナー(2桁ゼロ埋め) + ステージ文字(a/b/c…) + 連番` の形だった
（例 `1.04a9`）。これは PEP 440 と噛み合わない:

- **先頭ゼロが落ちる**: `1.04` は PEP 440 正規化で `1.4` になる。PyPI 上の表記が
  Version.h と食い違う。
- **ステージ文字の意味**: `a`/`b`/`c` を独自の開発段階として使っていたが、
  PEP 440 では `a`=alpha, `b`=beta が予約語で、`c` は無効。ごっちゃに使うと
  正規化・順序が破綻する。

## 新命名（1.4.1.dev1 〜）

### リリースセグメント: `メジャー . マイナー . ステージ`

- **ゼロ埋めしない**（`1.4`, `1.5`, …, `1.10`, `1.11`）。PEP 440 正規化で
  表記が変わらず、順序も数値比較で正しく単調増加する。
- 第 3 セグメントを **開発ステージ番号**として使う（旧 `a`/`b`/`c` を数値化）:
  `a → 0`, `b → 1`, `c → 2`, …

### 修飾子（PEP 440 が用意しているものだけを使う）

PEP 440 で使える修飾子は限られており、`fix` / `bugfix` / `patch` のような
**任意の文字列は使えない**（PyPI が正規化で拒否する）。用途別に次を使い分ける:

| 段階 | 表記 | 意味 | 正式版との順序 |
|---|---|---|---|
| 開発中 | `.devN` | 正式版に向けた開発版 | 正式版より**前** |
| 正式リリース | （修飾子なし） | 安定版 | — |
| リリース後の修正 | `.postN` | バグフィックス等、新機能を伴わない後追い修正 | 正式版より**後** |

- `.devN`（開発版）と `.postN`（リリース後修正）は **正式版を挟んで反対側**にある。
  まだ正式版を出す前の修正は `.devN` の連番を進めるだけにし、`.postN` は
  正式版を出した後の修正にのみ使う。

### バージョンの進み方（例）

```
1.4.1.dev1   ← 1.4.1 に向けた開発（TestPyPI で検証）
1.4.1.dev2
   …
1.4.1        ← 正式リリース（本番 PyPI 初投入）
1.4.1.post1  ← 1.4.1 のバグフィックス
1.4.1.post2
1.4.2.dev1   ← 次のステージ（c）の開発
1.4.2
   …
```

PEP 440 の順序で単調増加する:
`1.4.1.dev1 < 1.4.1.dev2 < 1.4.1 < 1.4.1.post1 < 1.4.2.dev1 < 1.4.2`

## 運用上の注意

- **`.devN` / `aN` / `bN` / `rcN` はすべて pre-release** で、`pip install pynaps`
  では取得されない（`pip install --pre pynaps` かバージョン明示が必要）。
  誰でも `pip install pynaps` で入れられる安定版を出すときは、修飾子なしの
  `1.4.1` のような版を使う。
- Version.h の `naps_version` が唯一の版の出どころ。CLI 表示（`naps --version`）、
  バイナリ名、`naps.__version__`、wheel 名、PyPI 登録名がすべてこの値に揃う
  （新命名は正規化で変化しないため一致する）。
- タグは Version.h と一致させる。CI（`ci/check_version_tag.py`）が PEP 440
  正規化で照合し、不一致ならタグパイプラインを止める。`v` 接頭辞は任意
  （`v1.4.1` でも `1.4.1` でも可）。
